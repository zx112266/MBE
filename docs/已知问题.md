  1. 这一版弹窗文案变了（例如「点击任意位置继续」「点击空白处关闭」），OCR 匹配不到；

- **待办**：冷启动复现，截图 + OCR 取准确文案与可点坐标，再改节点。

## 2026-10-31 打包启动失败（已修复）

- **现象**：启动即报「资源加载失败！请删除整个文件夹重新下载」。
- **根因**：10 个 pipeline 文件里都定义了同名节点 `屏保_待机`，MaaFramework 合并加载时报
  `key already exists [key=屏保_待机]`。
- **修复**：按文件改名（`屏保_待机_启动` / `_体力` / `_弥弥` / `_商店` / `_公会` / `_游园` / `_介质` / `_物资` / `_任务` / `_对策`），复检 0 处重复。

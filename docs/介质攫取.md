# 介质攫取（medium.json）

> 适用：`assets/resource/pipeline/medium.json`，任务名「介质攫取」，界面 1280×720。
> 最后更新：2026-11-08

## 一、入口与整体流程

```
大厅（OCR 前往作战）
 → 作战主菜单 → 刻印页（OCR 刻印，点 (837,676)）
 → 介质攫取入口（OCR 介质攫取，点 (640,533)）
 → 详情页（OCR 今日最高积分 [60,158,320,48]）
      ├─ 奖励红点闸门 → 有红点：领奖（见第二节）
      ├─ 今日最高积分 = 0 ？   ← 今天还没打过才开战
      │    ├─ 是 → 开始挑战（OCR 开始挑战，点 (1017,662)）
      │    └─ 否 → 直接返回大厅（今天已打过，打完也没奖励）
      └─ 开始挑战 → 队伍页 → 战斗等待（175 秒）→ 结算 → 确认
 → 详情页（第二段：奖励红点2 → 领奖）
 → 返回（点 (55,40)）→ 返回刻印 → 返回作战 → 完成
```

**每日只打一场**的判定：详情页左上「今日最高积分」，是 `0` 就说明今天没战斗过 → 开战；
不是 `0` 就说明今天已经打过 → **不再战斗，直接回大厅**（节点 `介质_今日积分0`，
expected `["今日最高积分0", "今日最高积分 0"]`，ROI `[81,163,210,34]`；命中走 `介质_开始挑战`，
否则走 `介质_返回`）。

## 二、奖励领取（2026-11-08 重写）

### 为什么重写

原实现靠 OCR 找「**一键领取**」四个字，但那四个字是**白字压橙色胶囊**，OCR 读不出来。
结果每次都走成「开面板 → 找不到 → 直接关面板」，奖励一直留在面板里，详情页左下「奖励领取」的红点永远消不掉。

### 新结构

```
介质_详情
  └─ 介质_奖励红点      ColorMatch 红 [170,40,40]~[255,120,120]，count 20，roi [176,625,26,26]
        ├─ 有红点 → 介质_奖励领取
        └─ 无红点 → 介质_开始挑战（跳过领奖）

介质_奖励领取           DirectHit 点 (95,659) 打开「奖励领取」面板
  └─ 介质_领奖面板      OCR「奖励领取」标题 roi [520,25,240,60] → 点 (1043,665) 一键领取
        ├─ 介质_领取弹窗  OCR「点击屏幕继续」/「获得物品」→ 点 (642,674)，自循环 max_hit 6
        └─ 介质_关面板    OCR「奖励领取」→ 点 ✕ (1135,60)
              └─ 介质_开始挑战
```

战斗结束后的 `介质_详情3` 用同一套：`介质_奖励红点2 → 介质_奖励领取2 → 介质_领奖面板2 → 介质_领取弹窗2 → 介质_关面板2 → 介质_返回`。

### 红点实测数据（10 次采样）

| 项 | 数值 |
|---|---|
| ROI | `[176,625,26,26]` |
| 红点外接框 | x 183–196、y 632–645（14×14），质心 (189,637) |
| 有红点时红像素 | 69 / 70 / 71 / 71 / 79 / 80 / 82 / 89 / 98 / 70（平均 77.9） |
| 无红点时红像素 | 0 |
| 对照区（左右/下方各 44×34） | 0 / 0 / 0 |
| 结论 | 阈值取 20，命中率 10/10，误报 0 |

### 面板行为

- 「本周「每日最高积分」累计」要达到某档才能领（8000 / 10000 / 12000 / 14000 / 16000 …）。
- 点一次「一键领取」，**所有可领档位合并成一个「获得物品」弹窗**（实测 4 档 = 材料 ×24 + 金币 ×8000）。
- 点「点击屏幕继续」(642,674) 回到面板，**已领的档位会从列表中消失**，剩下的显示「未完成」，此时底部「一键领取」也消失。
- 关闭只能点右上 ✕ (1135,60)；关掉后回到详情页，左下红点消失（实测 77 → 0）。

## 三、坑位记录

| 坑 | 说明 |
|---|---|
| 白字橙底按钮 OCR 读不出 | 「一键领取」「一键投喂」「一键派遣」都踩过，一律改 DirectHit 固定坐标 |
| `pre_delay` 不是“识别后延迟” | Maa 语义是识别**前**等待，用来等按钮出场动画 |
| 自循环节点必须给 max_hit | 否则点击未生效时会无限重试，任务挂死（2026-11-08 全库审计已统一补 10） |
| 结算页不能自引用 | `介质_等待结算.next` 曾写成 `[介质_等待结算, 介质_确认]`，结算页一直命中自己 → 死循环 17 分钟 |
